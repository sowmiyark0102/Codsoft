# Smart Rule-Based Chatbot 🤖

## 📌 Description
This project is a rule-based chatbot built using Python. It uses if-else conditions and pattern matching (regex) to respond to user inputs intelligently.

## ✨ Features
- Greets users and handles basic conversation
- Remembers user name
- Detects mood (happy/sad)
- Answers time and date queries
- Solves simple math problems
- Provides dynamic responses

## 🛠️ Technologies Used
- Python
- Regular Expressions (re module)

## ▶️ How to Run
1. Install Python
2. Run:
   python chatbot.py

## 🎯 Learning Outcome
This project helps understand:
- Natural Language Processing basics
- Rule-based systems
- Conversation flow design
