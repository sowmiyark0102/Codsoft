CODSOFT Internship – AI Project Portfolio

This repository contains Artificial Intelligence developed as part of the CODSOFT Internship program. The projects demonstrate practical implementation of core concepts in Natural Language Processing, Machine Learning, and Computer Vision using Python.

**Project Overview**

Each task focuses on applying theoretical concepts into real-world working systems.

**Task 1: Rule-Based Chatbot**

A simple conversational agent designed using rule-based logic to respond to user inputs.

Key Highlights:
- Rule-based response system using conditional statements  
- Pattern matching for input handling  
- Basic NLP-style conversation flow  

**Task 2: Recommendation System**

A hybrid recommendation engine that suggests movies based on user preferences.

Key Highlights:
- Content-Based Filtering using genre similarity  
- Collaborative Filtering using user rating behavior  
- Hybrid recommendation approach for improved accuracy  
- Personalized recommendations  

**Task 3: Face Recognition Attendance System**

A real-time face recognition system integrated with a GUI for automatic attendance marking.

Key Highlights:
- Real-time face detection using OpenCV  
- Face recognition using feature embeddings  
- GUI interface using Tkinter  
- Automatic attendance logging in CSV format  
- Handling unknown face detection  

**Technologies Used**

- Python  
- OpenCV  
- face_recognition  
- NumPy  
- Pandas  
- Scikit-learn  
- Tkinter
